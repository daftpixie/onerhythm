# Humble Docs Checklist

Apply to any README, documentation, user-facing copy, or marketing text.

## Voice standard
- [ ] Plain language, ~8th-grade reading level.
- [ ] Warm, humble, honest tone throughout.
- [ ] No hype, no hubris, no urgency, no growth-hacking language.

## Content rules
- [ ] Never rank suffering ("pain is not a competition").
- [ ] Educational framing only — medical judgment stays with the member and their clinician.
- [ ] Entity described correctly: "VT Infinite, Inc. d/b/a OneRhythm" — never "501(c)(3)."

## Anchor phrases (use sparingly and sincerely)
- "invisible bears" / "nobody should fight an invisible bear alone"
- "pain is not a competition"
- "Ad Astra Per Aspera"

## Red flags — if any of these appear, it's a bug
- [ ] Grandiose claims about impact or scale.
- [ ] Urgency or FOMO language ("don't miss out," "join now before...").
- [ ] Superlatives without evidence ("the best," "revolutionary," "groundbreaking").
- [ ] Passive-aggressive framing of competitors or alternatives.
- [ ] Language that implies the platform replaces medical care.

## Gate
- [ ] Read the text aloud. Does it sound like a person talking to a friend, or
      like a startup pitch deck? If the latter, rewrite.
