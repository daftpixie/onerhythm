# Accessibility rules — WCAG 2.2 AA, build-blocking

- Baseline user: 65+, older device, reduced vision/dexterity, low tech confidence.
- White/near-white background; body text >=16-18px; line-height >=1.5;
  Atkinson Hyperlegible / Inter.
- Contrast: text >=4.5:1; UI/focus >=3:1.
- Targets: >=24px any interactive (SC 2.5.8); 44px for primary actions.
- Visible focus ring everywhere (never removed).
- Plain language (~8th grade). Icon + TEXT label always — never icon-only.
- No autoplay, no carousels, no ambient/looping motion; honor
  prefers-reduced-motion.
- New 2.2 criteria: Focus Not Obscured, Consistent Help, Redundant Entry,
  Accessible Authentication (magic links/passkeys satisfy), Dragging alternative.
- The crisis affordance must be reachable from every screen; a silent failure to
  render it is a SAFETY incident, not a UI bug.
- Gate: automated axe + manual keyboard/screen-reader pass before merge.
