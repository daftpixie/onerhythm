## Release summary

OneRhythm is a peer-support prototype for people living with a heart-rhythm
condition and those who care for them. This source is published for review,
contribution and independent implementation under Apache-2.0. The OneRhythm
name and 1R mark remain reserved.

This version upgrades Expo to SDK 58 through tested intermediate SDK 57,
aligns React/React Native and test tooling, and removes critical/high findings
from the reviewed npm audit. Moderate/low build and test findings remain
recorded in PUBLIC_SOURCE_READINESS. It corrects population figures to match
the linked research, clarifies planned processor access, and includes the
bundled font license in the static export.

The hosted member platform is not open. The deploy configuration remains
landing-only with sign-up off. Source publication does not establish medical
benefit, clinical validation, regulatory clearance or readiness to host health
data. Native mobile distribution remains unverified.
